How Limits

A table of people. No account.

Keep the score.

Name the slate, add the players, pass the board around. The owner link is the only key. Bookmark it.

Two players minimum. Empty boxes are ignored. The form works with JavaScript off.

How

1

You get an owner page. That URL is the key. Anyone with it can add rounds.

2

The board link has no key. Leave it open on the table. It cannot edit.

3

Each round is one whole number per player. Totals update on the next load. The board refreshes itself.

Limits

  • 12 players. 200 rounds. Scores from -999 to 9999.
  • A slate lasts 30 days, then it is gone.
  • 8 new slates per IP per hour.
  • No accounts, no recovery. Lose the owner link and the board stays read only.
